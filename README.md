# Jewellery Design Desk

A sample jewellery design workflow management system built to demonstrate operational tracking and coordination across jewellery design processes.

## Overview

The Design Desk provides a structured interface for monitoring design batches and tracking work through different stages, from initial registration and selection to CAD processing and CAM handover.

## Key Features

- Design batch registration and tracking
- Manual design selection and status monitoring
- CAD job registration and designer allocation
- Branch-wise workflow visibility
- Design status monitoring
- CAM handover tracking
- Design history and operational overview
- Dashboard-based workflow visibility

## Technology Stack

- HTML
- CSS
- JavaScript

## Purpose

This project demonstrates the practical application of digital workflow management, operational coordination and process visibility in a jewellery design environment.

## Demo Data & Limitations

This is a demonstration project containing sample data. It is not connected to a live enterprise database or production management system. Browser-based changes are stored locally in the user's browser.
